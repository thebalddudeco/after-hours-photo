# After Hours Photo — Brand Application Notes

## Core palette

- Cream: `#F1E8DD`
- Yellow: `#FFB300`
- Red: `#F0392E`
- Brown: `#441F1D`
- Black: `#191919`

## Application rules

- Keep the existing website fonts unchanged.
- Use cream type on dark backgrounds.
- Use black type on yellow and cream backgrounds.
- Reserve red for restrained accents such as focus states, labels, and calls to action.
- Use yellow for major contact/footer moments and yellow section-label accents on dark sections.
- Use the seamless pattern only in limited, image-led executions; never place text over the pattern.
- Use the After Hours logo artwork as supplied; do not redraw or substitute the wordmark.
- Use the combined After Hours × The Bald Dude lockup in the footer only where it has enough scale and breathing room.
- Keep the navigation simple, high-contrast, and free of extra decorative icons.
- Use the yellow field for the About section, with high-contrast monochrome portraits providing the visual break between copy blocks.
- Present the About profiles horizontally on desktop in the order portrait, bio, portrait, bio; stack them on smaller screens.
- Use the repeat pattern in the footer as an image-led brand moment, keeping the footer copy and logo readable against the black field.
