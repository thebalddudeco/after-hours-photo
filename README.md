# After Hours Photo

One-page portfolio website for After Hours Photo, an editorial event photography studio covering commercial and private events.

## Local preview

Run any static web server from this folder. For example:

```powershell
python -m http.server 4173
```

Then open `http://localhost:4173`.

## Publishing

The site is configured for GitHub Pages and includes a `CNAME` for `www.afterhoursphoto.com`. DNS must be pointed to GitHub before the custom domain and HTTPS can finish activating.
